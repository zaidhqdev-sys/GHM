## Operation surface

```text

```

No toggle operation. No anonymous/public Saved Business surface. No HTTP route is implied by registry registration alone.

## Authorization boundary

```text
AuthContext -> authorization boundary -> service -> repository -> authorized transaction
```

`account_id` is derived from authenticated context. Mutations execute through:

- `ghm.create_saved_business(account_id, business_id)`
- `ghm.delete_saved_business(account_id, saved_business_id)`

No caller-controlled session identity variable is used.

## Schema

```text
ghm.saved_business
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
  account_id bigint NOT NULL -> ghm.account_identity(id) ON DELETE CASCADE
  business_id bigint NOT NULL -> ghm.business(id) ON DELETE CASCADE
  created_at timestamptz NOT NULL DEFAULT now()
  UNIQUE(account_id, business_id)
```
