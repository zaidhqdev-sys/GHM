# GHM Storage Key Qualification

This qualification covers only canonical provider-key construction.

Required invariants:

1. Business-logo keys use `media/logos/`.
2. Business IDs are numeric internal identifiers.
3. Object IDs are opaque UUIDs generated by GHM.
4. Unsafe/path-like business IDs are rejected.
5. User-controlled filenames are not part of provider keys.
6. Provider access remains behind `StorageProvider`.

Production storage is not qualified by this document.
