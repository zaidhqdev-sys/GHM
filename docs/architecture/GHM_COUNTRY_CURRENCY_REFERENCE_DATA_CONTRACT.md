# GHM Canonical Country and Currency Reference-Data Contract

**Status:** PROPOSED CONSTRUCTION CONTRACT — FOUNDER AUTHORIZATION REQUIRED
**Date:** 2026-10-03

## 1. Purpose

Define the smallest provider-neutral GHM reference-data boundary required to satisfy the already-authorized Commercial schema dependency on `ghm.country` and `ghm.currency`.

This contract does not authorize schema mutation, seed insertion, payment preparation, provider integration, shadow operation, or production cutover.

## 2. Ownership

GHM owns canonical country and currency reference identities used by GHM-owned resources.

Connect remains authoritative for its own regional configuration model. GHM must not copy Connect UUIDs, RLS policies, regional configurations, locales, administrative areas, provider configuration, or product pricing.

## 3. Currency

### `ghm.currency`

Minimum fields:
- `id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
- `code text NOT NULL UNIQUE`
- `name text NOT NULL`
- `symbol text NOT NULL`
- `minor_unit integer NOT NULL DEFAULT 2`
- `is_active boolean NOT NULL DEFAULT true`
- `created_at timestamptz NOT NULL DEFAULT now()`
- `updated_at timestamptz NOT NULL DEFAULT now()`

Required constraints:
- code is exactly three uppercase alphabetic characters;
- name and symbol are nonblank;
- minor_unit is between 0 and 6;
- active state is explicit and does not delete historical identity.

Currency code is the stable natural identifier. Numeric database IDs must never be assumed by application code.

## 4. Country

### `ghm.country`

Minimum fields:
- `id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
- `code_alpha2 text NOT NULL UNIQUE`
- `code_alpha3 text NOT NULL UNIQUE`
- `name text NOT NULL`
- `default_currency_id bigint REFERENCES ghm.currency(id) ON DELETE RESTRICT`
- `is_active boolean NOT NULL DEFAULT true`
- `created_at timestamptz NOT NULL DEFAULT now()`
- `updated_at timestamptz NOT NULL DEFAULT now()`

Required constraints:
- alpha-2 code is exactly two uppercase alphabetic characters;
- alpha-3 code is exactly three uppercase alphabetic characters;
- name is nonblank;
- default currency, when present, references an existing canonical GHM currency;
- country identity is retained rather than deleted when referenced by commercial history.

Country code is the stable natural identifier. Numeric database IDs must never be assumed by application code.

## 5. Runtime boundary

Runtime access is read-only for reference data.

Runtime receives SELECT on `ghm.country` and `ghm.currency` only. Runtime must not receive INSERT, UPDATE, or DELETE.

Reference-data mutation, if ever required, belongs to a separately governed administrative/migration authority and is outside Commercial payment preparation.

## 6. Seed authority

No country or currency rows are authorized by this document alone.

Any initial canonical rows must be introduced by an explicitly governed reference-data migration or existing canonical seed authority. Fixed numeric IDs must not be assumed.

Connect's existing South Africa (`ZA` / `ZAF`) and South African Rand (`ZAR`) records are source evidence only. They do not authorize copying those records or silently seeding them into GHM.

## 7. Explicit non-goals

This slice does not create:
- regions;
- locales;
- administrative areas;
- regional configurations;
- provider configuration;
- payment-provider records;
- commercial plans or prices;
- Connect-compatible UUID identities;
- public HTTP endpoints;
- product adapters.

## 8. Construction gate

**NOT AUTHORIZED FOR MUTATION.**

Before migration construction, the founder must authorize:
1. this bounded country/currency ownership model;
2. the initial reference-data seed authority and approved rows;
3. migration ordering before Commercial qualification;
4. the runtime read-only privilege boundary.

Until those decisions are authorized, Commercial payment preparation remains blocked at the reference-data dependency gate.
