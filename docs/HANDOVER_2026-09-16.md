Business Hours represents a Business-owned weekly operating schedule. It is distinct from instantaneous open-now state, booking capacity, holidays/exceptions, staff/resource availability, service-specific hours, and notification behavior.

The runtime boundary is least-privilege: SELECT is granted; runtime INSERT, UPDATE, and DELETE on the table are denied.
