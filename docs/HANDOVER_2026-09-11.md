## Enquiry resource state

The authoritative legacy Connect source contract is the `public.leads` marketplace-enquiry contract in the Zaid Connect repository. It was not copied blindly into GHM.

The current GHM governing contract is:

```text
docs/architecture/ENQUIRY_OPERATION_CONTRACT.md
```

Enquiry is a customer-to-Business relationship distinct from Project.

Canonical identity bindings:

```text
customer  -> ghm.account_identity.id
recipient -> ghm.business.id
```

Initial recipient authorization is deliberately limited to an active **owner** membership because the Connect source contract is owner-only. Do not broaden authorization to administrators or members without a new explicit contract.

Governed operations:

```text
enquiry.create
enquiry.readOwn
enquiry.readReceived
enquiry.updateStatus
```

Rules include authenticated customer creation, approved/active target eligibility, own-business denial, context-bound customer identity, `new` initial status, own-read isolation, active-owner received-read, owner-only lifecycle mutation, no delete, and no anonymous operations.

Lifecycle vocabulary:

```text
new -> contacted -> qualified -> quoted -> won | lost | archived
```

Source vocabulary:

```text
marketplace | directory | ai_quote | direct
```

Only the marketplace create path is initially eligible for implementation.

The Enquiry runtime ACL is intentionally least-privilege. Table-wide `SELECT` is allowed; table-wide `INSERT`, table-wide `UPDATE`, and `DELETE` are not granted. Approved create columns have column-level INSERT privilege, while only `status` has column-level UPDATE privilege. The repository therefore relies on the database default for `status = 'new'` and updates only `status` during lifecycle mutation.

The qualification harness explicitly asserts this table-level boundary and separately proves denial of unauthorized column mutations.

No notifications, realtime messaging, scoring, admin access, retention/anonymisation, anti-spam, payment, quoting, UI changes, provider migration, data migration, Supabase RLS replication, or automatic Project creation are included in this slice.
