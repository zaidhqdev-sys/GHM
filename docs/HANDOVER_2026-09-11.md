## Known PowerShell failures — do not repeat

Do not use large `node -e` commands containing multiline SQL, JavaScript template literals/backticks, or complex quoting. PowerShell has previously mangled those commands and caused Node syntax errors.

For a genuinely necessary read-only SQL audit, use a temporary `.cjs`/`.mjs` script and remove it afterward. Temporary scripts under `scripts\` must use `../dist/...` for compiled repository modules, not `./dist/...`.

For dedicated runtime audits, use `GHM_RUNTIME_DATABASE_URL` with TLS. Do not substitute `DATABASE_URL`; the canonical application pool uses `DATABASE_URL` and represents the legacy application path.
