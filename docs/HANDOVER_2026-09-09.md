# GHM Construction Handover — 2026-09-09

## Mission

GHM (GHM Core Engine) is being built as ZAID Technologies' own backend platform so Zaid Connect and QuoteFlow can eventually move away from managed backend dependency without production downtime.

## Non-negotiable production rule

Zaid Connect and QuoteFlow remain on Supabase until GHM is fully qualified. Do not change production environment variables, DNS, credentials, routing, or live product traffic during construction. Supabase remains the rollback path until controlled migration is complete.

## Architecture principles

- Mission Before Technology.
- Architecture Before Implementation.
- Documentation Before Code.
- Capability Before Provider.
- One concept → one owner → one canonical source.
- GHM is not a copy of Supabase.
- Product repositories remain authoritative for their application contracts.
- Never invent product schema from assumptions.

## Current qualification state

Build and runtime boundary verification have passed locally.

The transaction tests were initially placeholders. The current construction work upgrades the transaction boundary for dependency injection and adds behavior tests proving, without a live database:

- one checked-out client is used;
- `BEGIN` precedes successful work;
- `COMMIT` follows successful work;
- failed work triggers `ROLLBACK`;
- the client is always released;
- authorized transaction work receives the same authenticated `AuthContext` and checked-out client.

These are unit-level boundary proofs. They do not replace live PostgreSQL integration qualification.

## Database reconciliation gate

The live GHM PostgreSQL catalog has not yet been successfully captured from the current environment. Therefore no business/product tables may be invented or migrated yet.

Required evidence before the first canonical GHM business migration:

- PostgreSQL server/version;
- schemas;
- tables and columns;
- types/nullability;
- primary and foreign keys;
- delete behavior;
- unique constraints and indexes;
- sequences/identity definitions;
- views/materialized views;
- functions/procedures;
- triggers;
- RLS state/policies;
- grants/privileges;
- safe row counts.

`ghm.db` is a tiny legacy SQLite artifact and is not schema authority.

## Product evidence rule

Zaid Connect's Supabase schema is authoritative for Connect only and must not be copied into GHM by inference.

QuoteFlow also contains Supabase configuration, but inspected invoice persistence currently uses React Native AsyncStorage. Concrete remote calls must be inventoried before designing a QuoteFlow adapter.

For every GHM capability, record:

1. exact product repository/path;
2. concrete operation/API contract;
3. actual entities/fields;
4. authorization boundary;
5. consistency requirements;
6. rollback requirements;
7. remote/local/transitional status.
